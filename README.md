## ✨ Visão geral

A API combina armazenamento relacional e não relacional para administrar modelos reutilizáveis de checklist, relacioná-los aos equipamentos e registrar inspeções.

## 🚀 Funcionalidades

- Cadastro, listagem, atualização e exclusão de modelos de checklist
- Associação entre checklists e modelos de equipamentos
- Registro de inspeções
- Persistência no MongoDB e consultas no PostgreSQL
- Cache e controle de jobs com Redis
- Notificações com Firebase
- Autenticação e autorização com JWT
- Jobs programados, validação e health check
- Documentação OpenAPI

## 🧰 Tecnologias

| Área | Tecnologias |
| --- | --- |
| **Backend** | Java e Spring Boot |
| **APIs** | Spring Web MVC e Springdoc OpenAPI |
| **Segurança** | Spring Security e JWT |
| **Dados** | PostgreSQL, MongoDB e Redis |
| **Integrações** | Firebase Admin |
| **Mapeamento** | MapStruct e Lombok |
| **Build** | Maven e Docker |
